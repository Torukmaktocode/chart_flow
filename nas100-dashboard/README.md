# NAS100 Dashboard

Dashboard local de velas para NAS100 en estilo TradingView.

- URL local: http://127.0.0.1:8780/dashboard.html
- Fuente principal: Yahoo Finance `NQ=F`
- Respaldo: Yahoo Finance `^NDX`
- Temporalidades: 1m, 3m, 5m, 15m, 30m, 45m, 1h, 2h, 4h, D, S, M

Las temporalidades intradía se agregan desde datos base más finos para reducir saltos entre velas.
