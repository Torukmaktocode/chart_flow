# Trading War Room — FREE EDITION v3.0
## 100% gratuito · Sin API keys · Sin registro

### Instalación

```bash
npm install
node server.js
```

Luego abre `index.html` en Chrome. Ponlo en tu segunda pantalla junto a TradingView.
